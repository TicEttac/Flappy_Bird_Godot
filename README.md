# Flappy Bird Godot 4.5.1

## Description

This repository is my version of the game flappy bird. It is still a work in progress because i would like to implement a server part which could register high score.

## Usage

You can download the apk file onto your android device and then install it after allowing installation of foreign source's applications.

## Notice
